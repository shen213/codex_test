# 行者无疆 - 旅行网站

一个精美的中文旅行展示网站，多页面架构，纯前端实现，无框架依赖。

## 项目结构

```
travel-website/
├── index.html         # 首页 - 英雄区、快捷入口、精选目的地、好评预览
├── destinations.html  # 热门目的地 - 12个目的地卡片，支持按洲筛选
├── features.html      # 为什么选择我们 - 六大优势、服务流程、资质认证
├── gallery.html       # 旅行相册 - 12张风景照瀑布流，支持分类筛选与Lightbox
├── reviews.html       # 旅客评价 - 评价统计、8条精选评价轮播
├── contact.html       # 联系我们 - 联系方式卡片、咨询表单、FAQ手风琴
├── styles.css         # 全局样式与响应式布局
├── script.js          # 共享组件注入（导航栏/页脚）+ 各页面交互逻辑
└── README.md
```

## 页面功能

| 页面 | 功能 |
|------|------|
| 首页 | 全屏英雄区、搜索框、数字滚动统计、快捷入口卡片、精选目的地预览、好评预览 |
| 热门目的地 | 页面头部、按洲筛选（亚洲/欧洲/大洋洲/美洲/非洲）、12个目的地卡片 |
| 为什么选择我们 | 六大优势详解、五步服务流程、数据统计、资质认证展示 |
| 旅行相册 | 分类筛选（自然/城市/海岛/雪山）、12张照片瀑布流、点击Lightbox大图预览 |
| 旅客评价 | 综合评分统计卡片、8条评价轮播（自动播放/触摸滑动/圆点导航） |
| 联系我们 | 四种联系方式卡片、咨询表单、地图占位、5条FAQ手风琴 |

## 技术栈

- HTML5
- CSS3（CSS 变量、Grid、clamp 响应式字体、媒体查询）
- 原生 JavaScript（组件注入、IntersectionObserver、触摸事件、requestAnimationFrame）

## 使用方式

直接在浏览器中打开 `index.html` 即可预览。各页面通过导航栏互相链接。

## 响应式适配

| 断点 | 适配设备 |
|------|---------|
| > 1024px | 桌面端 |
| 768px - 1024px | 平板端 |
| < 768px | 移动端 |
